# Fischer's Adventure

A browser side-scrolling fishing game built with Phaser 3 + Vite + TypeScript.

## Play

```bash
npm install
npm run dev
```

## Controls

| Key | Action |
| --- | --- |
| A / D | Move |
| Space | Jump (also hold in catch minigame) |
| 1–5 | Select hotbar slot |
| Left click | Cast rod / hold in minigame |
| E | Inventory |

## v1 features

- Beach island with adjacent water
- Blocky player character
- 5-slot hotbar with starter rod
- Visible fish that swim toward the bobber
- Red `!` on bite
- Fisch-style catch minigame
- Common fish stacked in inventory
